# 意图胶囊 Intent Capsule

> 在 AI 对话里逐条勾选你说的话，一键打包带去另一个 AI 继续聊。

一款 Chrome 扩展（Manifest V3）。现有上下文迁移工具像"铲子"——整段对话搬走；意图胶囊是"手术刀"——你选哪条带哪条，默认只摘你自己的问题（用户 prompt 即意图浓缩，噪音最少）。

品牌色 `#EB4C89`，快捷键 `Alt+C` 展开面板。

## 为什么需要它

- **模型"变蠢"了**：聊太久上下文退化，重开对话又要从头解释
- **想换模型对比**：换一个助手要重打一遍需求
- **整段搬太乱**：现有工具搬走全部，AI 回复占大半，噪音太多

## 核心功能

- **逐条勾选**：每条消息旁注入 checkbox，「全选我的」一键选中所有用户消息
- **虚拟滚动全量收集**：对使用虚拟列表的平台采用边滚边捕获策略，不只选当前可见部分
- **时间胶囊头**：插件确定性生成来源标注（来源模型、日期、消息数），让新 AI 立刻明白背景
- **一键复制**：全本地，零网络延迟
- **AI 整理（可选）**：最小化润色，完整保留每一条消息（需在设置页填 API Key）

## 隐私

数据全存 `chrome.storage.local`，不读取对话内容，不上传任何数据。仅在用户主动使用「AI 整理」时，才会把选中消息发往用户自己配置的 API。

## 技术栈

- Chrome Extension Manifest V3
- TypeScript + esbuild
- 适配器模式：每个平台一份配置对象，核心逻辑不变
- 虚拟滚动方案：scrollAndCollect（边滚边捕获）+ 网络请求截获兜底
- postMessage 通信：MAIN world ↔ content script，nonce 防伪造

## 开发

```bash
npm install
npm run build      # esbuild 打包到 dist/
```

加载扩展：打开 `chrome://extensions` → 开启开发者模式 → 「加载已解压的扩展程序」→ 选本目录。
