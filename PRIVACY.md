# Privacy Policy / 隐私政策

**Intent Capsule (意图胶囊)**
Last updated: 2026-06-01

---

## English

### Data Collection

Intent Capsule does **not** collect, transmit, or store any personal data on external servers.

### What the extension accesses

- **Page content**: The extension reads message text only when you explicitly click a checkbox or use "Select All Mine". This data never leaves your browser except when you copy it yourself.
- **API Key**: If you choose to use the AI Polish feature, your DeepSeek API key is stored exclusively in your local browser storage (`chrome.storage.local`). It is sent only to `api.deepseek.com` to process your request — never to any other server.
- **No analytics**: The extension contains no tracking code, no analytics SDK, and no telemetry of any kind.

### Third-party services

The optional AI Polish feature sends selected message text to the DeepSeek API (`api.deepseek.com`). This is opt-in and only activated when you click "AI Polish". Please refer to [DeepSeek's Privacy Policy](https://www.deepseek.com/privacy) for how they handle API data.

### Contact

If you have questions about this policy, please open an issue at the extension's support page.

## 中文

### 数据收集

意图胶囊**不**收集、传输或在外部服务器存储任何个人数据。

### 扩展访问的内容

- **页面内容**：仅当你主动勾选复选框或点击「全选我的」时，扩展才会读取消息文本。这些数据不会离开你的浏览器，除非你自己复制粘贴。
- **API Key**：如果你使用 AI 整理功能，DeepSeek API Key 仅存储在本地浏览器存储（`chrome.storage.local`）中，只会发送给 `api.deepseek.com`，不经过任何中间服务器。
- **无追踪**：扩展不包含任何追踪代码、Analytics SDK 或遥测数据。

### 第三方服务

可选的 AI 整理功能会将你选中的消息文本发送至 DeepSeek API（`api.deepseek.com`）。这是可选功能，仅在你点击「AI 整理」时触发。关于 DeepSeek 如何处理 API 数据，请参阅 [DeepSeek 隐私政策](https://www.deepseek.com/privacy)。

### 联系方式

如有疑问，请通过扩展支持页面提交 Issue。
